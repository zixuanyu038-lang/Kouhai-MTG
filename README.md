# Kouhai-MTG
口嗨万智牌，战报回放
给万智牌对局换一种打法。导入 Endstep 回放，或用文字描述一个局面。让模型把想法整理成动作，由 Forge 校验费用、目标和结算，再导出可在 Endstep 播放的 .esreplay

安装包内的 runtime 目录包含第三方许可说明。 [Node.js 24.22.1](https://github.com/nodejs/node/tree/v24.22.1) · [Eclipse Temurin 17.0.20.1+1](https://github.com/adoptium/temurin17-binaries/releases/tag/jdk-17.0.20.1%2B1) · [Forge 2.0.15 源码](https://github.com/Card-Forge/forge/archive/refs/tags/forge-2.0.15.tar.gz)
